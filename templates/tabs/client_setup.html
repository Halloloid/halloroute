CLAUDE CODE

[UNSUPPORTED]

Claude Code talks to the Anthropic Messages API (/v1/messages). HalloRoute only implements the OpenAI-style /v1/chat/completions, so it cannot be pointed at this gateway directly.

  1. Run an Anthropic→OpenAI translation proxy in front of HalloRoute, or
  2. use one of the OpenAI-compatible clients below (Aider, OpenCode, Codex).

CURSOR

[NEEDS PUBLIC URL]

Cursor sends model requests from its own servers, so 127.0.0.1 is not reachable. Expose the gateway over a public HTTPS tunnel and use that URL.

  1. Open Settings → Models.
  2. Enable Override OpenAI Base URL and enter your public gateway URL ending in /v1.
  3. Paste your gateway key as the OpenAI API key.
  4. Add the selected model as a custom model and choose it.

SETUP SEQUENCEgenerate · export · verify

      

        

          
01 GENERATE KEY

          
Use GENERATE KEY above. The new key is injected into every snippet on this page.

        

        

          
02 EXPORT THE ENVIRONMENT VARIABLE

          
Add to your shell config (~/.bashrc, ~/.zshrc) so every tool inherits it.

          
export HALLOROUTE_API_KEY="YOUR_HR_LIVE_KEY"

        

        

          
03 VERIFY THE GATEWAY

          
Listing models confirms the key is accepted and routing works.

          
curl -s {{ base_url }}/models \
   -H "Authorization: Bearer $HALLOROUTE_API_KEY"

        

        

          
04 POINT YOUR CLIENT AT THE GATEWAY

          
Follow the steps on a client card and use its COPY CONFIG button.

          
base url: {{ base_url }}
   model:    MODEL_ID
