SETUP SEQUENCEexport · verify · connect

01 GENERATE KEY

Selected key is injected into every snippet on this page.

export HALLOROUTE_API_KEY=
  hr-live_default

02 EXPORT THE ENVIRONMENT VARIABLE

Shell config (~/.bashrc, ~/.zshrc) so every tool inherits it.

export HALLOROUTE_API_KEY="hr-live_default"
source ~/.bashrc
env: HALLOROUTE_API_KEY set

03 VERIFY THE GATEWAY

One request against the model catalog confirms routing.

curl -s http://127.0.0.1:20128/v1/models \
  -H "Authorization: Bearer $HALLOROUTE_API_KEY"
→ 200 OK · free models · local edge

04 POINT YOUR CLIENT AT THE GATEWAY

Pick a client card on the left and press COPY CONFIG — the snippet ships with the selected key baked in.

claude, cursor, aider, opencode, sdk: py / node
→ gateway base url: http://127.0.0.1:20128/v1
